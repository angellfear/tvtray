# Пресеты TvTray

Каждый файл `*.json` в этой папке — настройки макроса подсветки для серии или модели ТВ.
TvTray скачивает их кнопкой **«Обновить с GitHub»** в настройках (раздел «Подсветка»)
и при добавлении ТВ сам применяет подходящий пресет.

## Формат

```json
{
  "id": "samsung-2016-ku",
  "name": "Samsung 2016 KU (Tizen 2.4)",
  "models": ["UE49KU6470"],
  "modelPattern": "^(UE|UN|UA)\\d{2}KU\\d",
  "backlight": {
    "openKeys": ["KEY_MENU", "KEY_ENTER", "KEY_DOWN", "KEY_ENTER"],
    "closeKeys": ["KEY_EXIT"],
    "max": 20,
    "navDelayMs": 340,
    "stepDelayMs": 100
  }
}
```

| Поле | Значение |
|---|---|
| `id` | Уникальный идентификатор, совпадает с именем файла |
| `name` | Название в списке пресетов |
| `models` | Точные модели, проверенные на реальном ТВ (имеют приоритет) |
| `modelPattern` | Регулярное выражение для серии (`modelName` из `http://<ТВ>:8001/api/v2/`) |
| `backlight.openKeys` | Кнопки, после которых на экране активен ползунок подсветки |
| `backlight.closeKeys` | Кнопки, закрывающие меню |
| `backlight.max` | Максимум шкалы подсветки |
| `backlight.navDelayMs` | Пауза после каждой кнопки меню, мс |
| `backlight.stepDelayMs` | Пауза между нажатиями ◀/▶, мс |

## Как добавить свой ТВ

1. Подберите последовательность в настройках TvTray (мини-пульт с флажком «Сразу нажимать на ТВ»).
2. Скопируйте значения в новый файл `presets/<производитель>-<год>-<серия>.json`.
3. Пришлите pull request — укажите модель, на которой проверяли.
